# 21 - R2.6 Draft Persistence Specification

## Purpose

Add reliable local draft persistence for UI Studio Builder so authoring progress survives refreshes and accidental navigation.

## Key Behaviors

- LocalStorage-only persistence in this phase.
- Debounced auto-save at 1.5 seconds after draft changes.
- Save status surfaced in top bar: `Saving`, `Saved`, `Recovered`, `Error`.
- On load:
  - valid compatible draft restores automatically
  - invalid/incompatible payload triggers safe reset with backup snapshot and user notice

## Contracts

- `BuilderDraftPersistenceEnvelope`
- `BuilderDraftRecoveryResult`
- `BuilderPersistenceError`
- `BuilderSaveState`

## Guardrails

- No backend persistence in this phase.
- No route/nav exposure changes.
- Scope isolated to `src/ui-studio/*` and `UI Studio/*`.
