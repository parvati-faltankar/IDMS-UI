# 23 - R2.7 Rule Condition Builder Specification

## Purpose

Upgrade behavior rule authoring from single-line condition edits to a guided visual condition builder with deterministic structure and strict validation.

## Key Behaviors

- Visual authoring for condition groups and rows:
  - group type: `all` / `any`
  - add condition row
  - add subgroup
  - update operator/source/value
  - remove/reorder nodes
- Supported operators remain:
  - `equals`, `notEquals`, `contains`, `greaterThan`, `lessThan`, `isEmpty`, `isNotEmpty`
- Maximum supported condition depth: 2.

## Contracts Added

- `BuilderConditionLeafDraft`
- `BuilderConditionGroupDraft`
- `BuilderConditionNodeDraft`
- Condition operation payloads:
  - add group
  - add leaf
  - update node
  - remove node
  - reorder node

## Validation Enhancements

- Block empty condition groups.
- Block malformed condition node shapes through existing condition validation checks.
- Block unsupported operators.
- Block condition depth above 2.
- Preserve deterministic issue mapping to `ValidationIssue` (`code`, `path`, `blocking`).

## Hard Freeze Compliance

- No route or navigation exposure changes.
- No changes to existing app pages/components/styles outside approved UI Studio boundaries.
- All changes isolated to `src/ui-studio/*` and `UI Studio/*` docs.
