# 19 - R2.5 UX Intelligence Specification

## Purpose

Harden UI Studio Builder usability so it feels intelligent, guided, and production-grade while staying isolated to `src/ui-studio/*`.

## Key UX Upgrades

- Introduce builder-scoped UX contracts:
  - `UiStudioDesignTokens`
  - `UiAssistHint`
  - `UiFeedbackState`
- Add guided smart-assist hints for layout sequencing and safer authoring flow.
- Add inline success/error feedback for authoring operations (no global side effects).
- Improve information hierarchy with stronger visual structure and actionable microcopy.

## Layout Editing Continuation

- Extend UI controls for row/column authoring:
  - add/remove/reorder row
  - add/remove/reorder column
  - explicit field move to selected column
- Keep operation behavior deterministic and in-memory only.
- Keep hidden feature-flag route behavior unchanged.

## Validation Readability

- Add validation presentation adapter:
  - maps existing `ValidationIssue[]` into grouped blocking/warning/info view
  - preserves existing validation schema and contracts
- Surface first blocking issue reference in validation panel for faster triage.

## Hard Freeze Compliance

- No changes to existing app pages/routes/styles outside approved UI Studio integration points.
- All UX uplift changes remain in `src/ui-studio/*` and documentation in `UI Studio/*`.
