# Help & Microcopy Library

## Tone

Use clear, calm, business-friendly language. Do not write technical explanations unless the user needs them.

## Global Help Topics

### Admin Dashboard

Use Admin Dashboard to complete key setup before business users start creating documents. Start with Organisation, then Numbering, Picklists, KYC, Roles, and Templates.

### KYC Setup

KYC Setup defines which proof documents are required for a customer, supplier, employee, vendor, or partner. Rules can differ by entity type and country.

### Picklist Master

Picklist Master controls dropdown values used across the application. It supports simple lists, dependent lists, and multi-level dependent lists.

### Numbering & Code Setup

Numbering & Code Setup controls prefixes and numbering rules for masters and transaction documents.

### Code Generation Policy

Code Generation Policy defines the final code format, sequence, reset rule, and activation status for a specific entity.

## Field Help Examples

### Regex Pattern

Use regex only when a document number must follow a strict format. Regex overrides simpler character and length rules.

### Prefix Value

Prefix is the fixed text added before the generated number, such as PO, SO, CUST, or SUP.

### Series Type

Series Type decides whether numbering continues forever or resets by calendar year, financial year, month, or day.

### Reset Frequency

Reset Frequency controls when the counter starts again from the reset number.

### Number Consumption Event

This decides when the number is permanently used, such as on Save Draft or on Submit/Activate.

### Entity Type

Entity Type narrows the setup to a specific business category, such as Individual Customer or Corporate Customer.
